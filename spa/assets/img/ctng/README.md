# CTNG artwork

Historical Cybertown NG (Next Generation) artwork, used by the CTNG Beta landing page.

Both files are **copies** of material already held in the workspace collection at
`~/Projects/cybertown/ctng/archive/cybertownng-site/images/`, which is itself gathered from
the archived `cybertownng` site. Nothing here was drawn, generated, edited or recoloured for
CTR — the bytes are the archived bytes, renamed only so the filename says what the image is.

Ryan approved the use of this specific source directory ("the art by Syd and the renders")
on 2026-09-03. That approval covers this directory; it is not a general licence to add other
CTNG art. Anything new needs asking first.

| file | source | what it is |
| --- | --- | --- |
| `ctng-masthead.jpg` | `cybertownng-site/images/mainflat.jpg` | The CTNG front-page masthead — the "CYBERTOWN NG / NEXT GENERATION" wordmark over a composite of the project's renders. This is the CTNG logo as the project itself used it. |
| `ctng-transport-gate.jpg` | `cybertownng-site/images/gate.jpg` | "TRANSPORT GATE — CYBERTOWN NG", concept art by Syd Mead's studio, as published on `gate.html`. |

## A note on the masthead

`mainflat.jpg` has the old site's navigation strip (VISION / CONCEPT ART / SCREENS / FAQ /
3D MODELS) baked into its bottom ~35 pixels; on the original page those pixels were an image
map. The landing page clips them off in CSS rather than editing the file, so the image stays
byte-identical to the archive and no dead-looking buttons are shown to a visitor.
